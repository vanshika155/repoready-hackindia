# Before you submit

This starter project is provided as a ZIP. To meet the HackIndia requirement that the work be yours and commits come from `@vanshika155`:

1. Extract the ZIP.
2. Review and personalize the app and README; make improvements you understand.
3. Create a new public GitHub repository under `vanshika155`.
4. Upload the project files or push them from your own Git setup.
5. Make your own meaningful commits while signed in as `@vanshika155`.
6. Verify the public repository and README in an incognito window.
7. Paste the public repository URL into HackIndia.

Do not claim that this ZIP itself proves commit history. GitHub commit history is created when you commit and push the project from your own account.
